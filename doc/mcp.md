# MCP：让 Agent 观察并操作手机

MobilePlayHelper 0.3.0 提供本地 stdio MCP 服务。它直接调用客户端原生控制接口，再通过 scrcpy 的控制通道向手机发送触摸，不使用桌面鼠标模拟或 Computer Use。

## 安装与连接

使用完整 Windows ZIP 便携版，或先构建源码。MCP 服务需要 Python 3.12+，不需要额外 pip 包。普通手动游玩不需要 Python。

将以下配置中的绝对路径替换为你的实际目录，再加入支持 stdio MCP 的 Agent 客户端：

```json
{
  "mcpServers": {
    "mobile-play-helper": {
      "command": "python",
      "args": ["D:/MobilePlayHelper/scripts/mcp_server.py", "--root", "D:/MobilePlayHelper"]
    }
  }
}
```

服务通过标准输入输出传输 JSON-RPC；标准输出只承载协议。支持 initialize、ping、tools/list、tools/call 和取消通知；协商协议版本 2025-06-18，也兼容 2024-11-05 / 2025-03-26。没有 HTTP 监听端口。

先调用 `mph_start`。服务启动自己管理的客户端，默认使用独立的 `default` 配置；多台设备时用 `serial` 指定设备。默认 1280 长边 / 30 FPS / 4 Mbps、关闭音频和剪贴板同步，以便截图和轻量交互。这是 MCP 会话的启动配置，不是游戏性能推荐。

MCP 数据默认位于 `%LOCALAPPDATA%/MobilePlayHelper/MCP/`，也可用 `--data-dir` 指定。个人键位与普通版分开保存。程序在运行中不自动接管其他已经打开的 MPH 客户端。

## 工具

| 工具 | 作用 |
|---|---|
| `mph_start` / `mph_stop` | 启动和关闭本服务拥有的客户端 |
| `mph_state` | 查询投屏尺寸、FPS、映射/编辑状态、按键及摇杆区域 |
| `mph_screenshot` | 返回真实 PNG：手机画面、MPH 覆盖层和右侧工具栏；可等待 0–2000ms，也可遮挡一个敏感矩形 |
| `mph_mapping` | 开启或关闭键鼠映射；不模拟按 F1 |
| `mph_editor` | begin / save / discard：进入、保存或放弃编辑 |
| `mph_profile` | 在 MCP 数据目录新建或加载配置；新建不覆盖同名文件 |
| `mph_binding` | 增加、移动或删除按键点位；需要编辑模式 |
| `mph_zone` | 修改移动摇杆、视角区域和灵敏度；需要编辑模式 |
| `mph_tap` | 真实点击或长按：50–5000ms，默认 100ms |
| `mph_swipe` | 真实单指滑动：50–5000ms，默认 350ms |
| `mph_cancel` | 请求释放当前触点并关闭映射 |

触摸坐标为手机整幅画面的归一化坐标：左上角 `(0,0)`，右下角 `(1,1)`，不包含工具栏。截图可能比手机原始分辨率小；不要将包含工具栏的整张截图宽度用于计算触摸 X 坐标。

## 示例：观察 → 点击 → 确认

```text
mph_start({"profile":"daily-demo"})
mph_screenshot({"settle_ms":300})
# 根据截图确认目标，而不是照抄未知游戏中的固定坐标
mph_tap({"x":0.75,"y":0.80})
mph_screenshot({"settle_ms":500})
```

长按和滑动：

```text
mph_tap({"x":0.80,"y":0.70,"duration_ms":700})
mph_swipe({"x":0.20,"y":0.75,"to_x":0.20,"to_y":0.50,"duration_ms":600})
```

配置示例：先关闭映射，进入编辑，再将 Space 放在跳跃按钮上，最后保存：

```text
mph_mapping({"enabled":false})
mph_editor({"action":"begin"})
mph_binding({"key":44,"x":0.90,"y":0.72})
mph_editor({"action":"save"})
```

按键编号采用 SDL 物理扫描码，例如 Space=44、R=21、C=6；鼠标左/右/中键分别为 513/515/514。F1–F12、反引号、Num Lock 和小键盘运算键保留给工具，不能新增为游戏绑定。

## 简单挂机玩法的边界

Agent 可以结合截图、点击、长按和滑动，在已授权的设备上执行简单的领取、收菜和菜单操作。本项目提供控制能力，尚未内置针对某款游戏的奖励识别、每日任务脚本或成功率保证。

建议每一步重新观察并确认结果，为流程设置操作次数和总时长上限；遇到未知弹窗、付费、物品消耗或账号相关操作时暂停，按用户给出的授权处理。不要把工具返回成功当作奖励到账。

`delivery=queue_only_not_game_ack` 只表示触摸进入 PC 控制队列。断线、游戏卡顿或游戏自身规则可能使其未生效。第一版仅支持单指手势，不支持多指并行、无限按住或反作弊绕过。真实触摸仅在普通模式可用；编辑和键鼠映射开启时拒绝触摸命令。

客户端失焦、手动键盘/鼠标输入、断线和取消会终止远程手势；临时队列拥塞时会重试抬指。进程被强杀或 USB 断开时，不能保证抬指消息送达。普通模式下，Agent 无需将桌面窗口置前就能通过原生接口操作。

每个服务同一时间只接受一个普通工具操作；并发命令返回 busy，取消可独立执行。操作超时视为结果未知，服务要求重启会话，避免盲目重试产生重复操作。

## 隐私与权限

MCP 是对当前用户设备的操作授权。服务不开放网络端口，原生通道仅在子进程设置 `MPH_MCP_DIR` 后启用；本机同一用户的进程属于同一信任边界。不要让不可信进程或远程共享目录访问会话文件。

截图会作为 MCP 工具结果发送给接入的 Agent，可能包含账号、聊天或通知。公开图片前检查内容；`mph_screenshot` 的 `mask` 可在导出图中遮挡一个矩形，不改变手机画面。会话目录保存最新截图和控制请求/响应，不自动清理历史会话；不再需要时退出服务后删除对应目录。

遵守游戏服务条款。游戏画面、名称和素材归相应权利人所有，本项目与游戏厂商无隶属或背书关系。
