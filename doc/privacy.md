# 隐私与诊断

本项目在本机保存运行和诊断数据。当前诊断实现未包含自动上传功能；用户主动上传 GitHub Issue、视频或日志属于另行分享。

## 默认诊断

默认连接后启动诊断，记录 PC 进程和内存指标、手机前台应用包名、进程号、设备信息、系统退出历史以及筛选的 logcat。系统日志可能包含应用输出的额外信息，不应假定全部内容都不敏感。最近六个诊断会话按大小轮转；具体限制见 [内存诊断](memory-diagnostics.md)。

启动前设置 `MPH_DIAGNOSTICS_OFF=1` 可关闭独立内存诊断。此开关不关闭主程序运行日志、映射时序 CSV，也不禁止用户主动录制。

开发版数据位于 `dist/`；单文件版位于 `%LOCALAPPDATA%\MobilePlayHelper\Standalone\runtime/<版本摘要>/dist/`，或 `MPH_PORTABLE_HOME` 指定目录。退出程序和诊断进程后，可删除 `diagnostics/`、运行日志及 `MobilePlayHelper-look.csv*`；不要删除 DLL 或个人键位文件。旧运行版本目录不会因六会话轮转而全部自动清理。

## 用户主动录制

点击录制后保存手机画面、手机声音和鼠标/触点事件到 `%TEMP%\MobilePlayHelper`。画面和声音可能包含账号、聊天和通知等内容。录制结束后请自行查看并删除不需要的文件；临时目录不是保密或自动到期的保证。

## 分享前

优先提供最小错误片段。检查并遮盖设备序列号、用户名、本地路径、账号、应用包名、聊天及无关系统日志。不要上传 ADB 密钥、凭据或未经检查的完整诊断目录。

## 设备授权

只在你有权控制的设备上开启 USB 调试并授权电脑。ADB 授权允许电脑控制设备；不再使用或使用了不可信电脑后，应在手机开发者选项中撤销相应调试授权。

## MCP 会话

MCP 截图会返回给接入的 Agent，是否离开本机取决于 Agent 平台的数据处理方式。服务本身不自动上传，但不能因此宣称 MCP 截图永不离开设备。独立数据目录保存最近截图、请求/响应和日志，历史会话不自动轮转。详见 [MCP 说明](mcp.md)。
