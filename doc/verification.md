## 鼠标快速滑动与越界手势节奏

- 代码检查发现原实现会在单次鼠标事件内密集发送 UP/DOWN/MOVE，快速移动时反复重新落指。此事实不能直接证明游戏停转根因，但属于明确的兼容性风险。
- 改为累计鼠标相对位移、约 8ms 一次由 UI 线程发送最多一条触摸事件；SDL timer 只投递合并事件，不操作触摸状态。到边缘先完成可用位移，再分开抬起/落指/移动；剩余位移和发送失败重试保留。
- 映射开启才创建计时器，关闭/失焦销毁并清空积压；正常状态没有定时发送。极端输入有界限，退出映射日志记录越界重新落指、发送失败及输入超限次数。
