# 键位配置格式



```text
# 归一化坐标 0..1；.16 = 画面宽度 16%，.76 = 画面高度 76%
toggle 58
joystick .16 .76 .10
look .65 .45 .20 .001
bind Mouse1 .90 .52
bind Space .90 .73
bind R .72 .84
```

`joystick x y radius`；`look x y radius sensitivity`。半径使用画面**高度**的比例，X 偏移再按宽高比换算，避免宽屏上的圆形摇杆变成椭圆。`bind` 坐标分别使用宽高比例。文件不保存屏幕像素坐标。

编辑器保存按键时使用 SDL 物理扫描码 `Key44` 等；这样按键位置不受大小写影响。Mouse1/2/3/4/5 为左/右/中/侧键。`toggle` 使用物理扫描码（58 为 F1；旧配置中的其他切换键会在加载时统一为 F1）。重复按键、非法范围、NaN、未知配置项会拒绝加载。F1–F12、·、Num Lock 和小键盘运算键保留给工具，不参与点位映射；Esc、Delete、加减号、方括号均可绑定。WASD 默认控制摇杆，若给其中某键单独配置点位，该键优先触发点位。旧配置中的功能键点位会忽略，其余点位保留。

通过 `MPH_PROFILE` 指定完整配置路径也可以直接运行 exe。未指定时使用 EXE 所在位置对应的 `profiles/default-fps.mph`；不存在则使用内置模板。配置位置不依赖启动时工作目录。保存先写临时文件，再重命名覆盖；失败不会退出编辑器。
