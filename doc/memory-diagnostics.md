# 内存诊断

Windows 版默认启用，无需命令行。根目录入口和直接启动 dist/MobilePlayHelper.exe 都会在连接成功后启动独立的 mph-diagnostics.exe。收集在本机完成，不上传数据，不需要 root。

## 日志位置

`dist/diagnostics/session-日期-时间-客户端PID/`：每次连接单独建档。

| 文件 | 内容 |
| --- | --- |
| memory.log | PC 客户端工作集、峰值工作集、私有提交量、缺页次数、句柄/GDI 对象数量；诊断进程自身占用；PC 系统内存；客户端实际退出码 |
| phone.log | 手机时间/运行时长、MemAvailable、交换区和内核内存统计、OOM/换页计数；前台应用与 PID；scrcpy 投屏服务 PID；游戏和投屏进程 RSS、峰值、线程数、CPU 累计值、oom_score |
| detail.log | 周期性 Java/Native/Graphics/PSS/RSS 明细、编解码服务与 SurfaceFlinger 占用、系统历史进程退出原因；结束时再补采一次 |
| events.log | 持续接收的低内存清理、进程死亡、Java/native 崩溃与编解码错误等相关 logcat 事件，及 MPH_DIAG 手机侧内存摘要 |
| client.log | 该会话的 MPH 主日志尾部，包含纹理尺寸切换与模式变化；绑定原日志文件句柄，避免快速重启后归档成下一轮日志 |

手机探针位于 `scripts/mph-phone-probe.sh`，随发布复制到 dist。它由 ADB 在手机上短时执行读取，并用 `MPH_DIAG` 标签把摘要写入手机系统日志环形缓冲区。没有在手机上增加常驻应用，也没有改动原投屏服务的捕获/输入逻辑。手机侧系统日志缓冲区有容量限制、重启会丢失，因此 PC 持续接收是主要留存方式。

## 频率和边界

- PC 内存通常每 5 秒一条；手机基础数据每 30 秒一组；详细数据每 120 秒一组。ADB 采集期间 PC 采样会有延迟，实际间隔以记录时间为准。
- 系统事件连续接收，每 30 秒重新建立一次接收窗口，并重读少量尾部以减小切换遗漏。日志可能有重复，按手机时间、PID、事件内容去重；窗口结束标记 `truncated_or_timeout=1` 对这种持续 logcat 读取是预期行为。
- ADB 基础、详细、最终事件采集分别有 10/15/5 秒超时。只结束诊断创建的命令进程，不执行 adb kill-server，不关闭游戏，也不注入游戏输入。客户端结束后，诊断通常在约一分钟内自动结束。
- 每类滚动日志约 4 MiB 一份，另保留一份 `.previous`；保留最近 6 个会话，正常情况下诊断目录上限约 216 MiB（另有少量记录头尾）。记录到本地磁盘；请及时复制重要会话，避免后续启动轮换掉证据。
- 无 root 时部分 `/proc`、内核或厂商日志可能无权读取，日志会保留 `Permission denied` 等结果。这表示未知，不能按零占用处理。
- 不做 heap dump、不主动触发 GC、不更改手机内存管理参数。没有承诺零开销；诊断进程自身的内存也会记录。

## 出现问题后

保留对应完整会话目录，连同 `dist/MobilePlayHelper.log`、`.log.previous` 和 `MobilePlayHelper-launcher.log`。需要查看以下时间关系：投屏服务 Java/Native/Graphics/PSS 是否先持续上涨，系统 MemAvailable 是否下降，哪个进程被 LMK 清理，期间是否发生横竖屏/编码器变化，以及 PC 客户端的退出码。

如果游戏结束后 MPH 仍在投屏，周期性详细快照也会保存系统退出历史；无需故意关闭或重新启动游戏来触发记录。若 USB 已断开，手机不能读取时将记录超时或设备离线，之前已流到 PC 的数据仍保留，无法保证补采手机离线期间的记录。

短时采样正常不能证明不存在泄漏。排除泄漏仍需要在相同场景对比不投屏/投屏、横竖屏切换和长时间运行的趋势；不能简单相加不同进程 RSS 作为物理内存总占用，也不能只凭 VmSize 很大就判定泄漏。

如需做不带诊断的对照实验，可在启动环境中设置 `MPH_DIAGNOSTICS_OFF=1`，随后重新启动 MPH。正常使用不需要设置。日志包含本地进程名、应用包名、时间和相关系统异常信息，分享前可先检查；不采集游戏画面、键盘输入内容或完整内存转储。

## 验证

`python scripts/test_diagnostics.py` 使用隔离的假 ADB 测试正常/异常退出、采集超时、输出上限、轮转、保留数量、非诊断文件保护、含空格与中文路径，以及快速重启时原始主日志归档。该测试不连接手机。
